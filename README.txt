BIRTHDAY WEBSITE - HOW TO RUN
1. In VS Code: File -> Open Folder -> jinni-birthday-website.
2. Install the "Live Server" extension, right-click index.html -> Open with Live Server.
   (Or in a terminal: python -m http.server 5500, then open http://localhost:5500)
   Double-clicking index.html also works, but the mic feature only works on localhost/https.
3. Fonts need an internet connection (Google Fonts).

HOW TO EDIT:
- Top of script.js: NAME, REASONS, SHAYARI (poems), WISHES, COUPONS, CP (photo captions)
- script.js: TL = the teddy's speech bubble lines
- index.html: the letter text is inside <div id="paper">
- images/: replace p1.jpg ... p4.jpg with your own photos (keep the same names)
